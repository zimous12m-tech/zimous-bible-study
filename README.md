# 📖 Zimous Bible Study

> **"A Bíblia guiada como um mentor faria."**

O **Zimous Bible Study** é uma aplicação web progressiva (PWA) desenhada para revolucionar a forma como as pessoas estudam as Escrituras. Muitas vezes, o estudo da Bíblia é difícil porque não há um mentor por perto para explicar o contexto, as aparentes contradições ou como aplicar os textos à vida real. O Zimous resolve esse problema ao fornecer um ambiente de estudo profundo, didático e acessível para crentes, não-crentes e curiosos.

### 🚀 Aceder à Aplicação (Live Demo)
A aplicação está totalmente online, não precisa de instalação e pode ser usada em qualquer dispositivo (PC, Tablet ou Telemóvel). Pode até ser adicionada ao ecrã inicial do telemóvel para funcionar como uma App nativa.

## ✨ Funcionalidades Principais

A app foi construída em torno de três pilares fundamentais:

### 1. 📚 Estudo por Temas (O Mentor)
Em vez de ler a Bíblia como um livro comum de início ao fim, o utilizador diz o que está a sentir (ex: *Depressão, Ansiedade, Luto, Perdão, Finanças*).
A app responde com:
*   **A Perspetiva de Deus** sobre o tema.
*   **Exemplos** de personagens bíblicos que passaram pelo mesmo.
*   **Soluções práticas** e passos a dar.
*   **Versículos-chave** cruzados para leitura.

### 2. 🛡️ Dúvidas e Aparentes Contradições (A Prova dos 9)
Um espaço seguro para os questionamentos mais difíceis. A app responde a dúvidas reais e aparentes contradições da Bíblia (ex: *Quantos animais entraram na Arca? Quem matou Golias? A Bíblia apoia a escravidão?*).
*   Resposta curta e direta.
*   Contexto histórico e literário.
*   Explicação aprofundada.
*   Versículos para o utilizador ler e verificar por si mesmo.

### 3. 🔎 Motor de Pesquisa Avançado
*   Pesquisa por todos os termos (AND) ou qualquer termo (OR).
*   Pesquisa por frase exata.
*   Concordância bíblica.
*   Análise contextual (palavras que aparecem juntas).

## 🛠️ Tecnologias Utilizadas

Este projeto foi desenvolvido com foco na simplicidade, performance e zero dependências externas complexas:

*   **Backend:** Python 3 (Servidor HTTP nativo, motores de pesquisa construídos de raiz).
*   **Frontend:** HTML5, CSS3, JavaScript Vanilla (Design responsivo e Dark Mode).
*   **Base de Dados:** Ficheiro JSON (Tradução Almeida Atualizada).
*   **Deploy & Cloud:** Render.
